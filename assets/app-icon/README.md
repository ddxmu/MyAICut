# MyAICut app icon

Original artwork for this fork: a camera lens, a strip of 35 mm film and the word
**CUT**, on a dark violet-tinted tile.

## Files

| File | What |
|---|---|
| `filmcraft.svg` | canonical artwork (1024-unit viewBox) |
| `filmcraft-small.svg` | the same artwork for scalable Linux installs |
| `filmcraft-1024.png` | 1024 px full-bleed render |
| `filmcraft-macos-512.png` | runtime Dock icon on macOS, with Apple's transparent margin |
| `filmcraft.icns` | macOS bundle icon (`CFBundleIconFile`) |
| `filmcraft.ico` | Windows icon, 16–256 px |
| `hicolor/<size>/apps/com.myaicut.app.png` | Linux icon theme |

The macOS renders put the 824 px tile body in a 1024 px canvas so the Dock icon
matches the size of other apps. Windows, Linux and the web use the full-bleed tile.

The icon is MIT OR Apache-2.0, like the rest of this fork. It replaces the upstream
FilmCraft owl artwork and contains no ArtCraft trademark assets.
